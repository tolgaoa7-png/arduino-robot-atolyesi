Proje 01 · başlangıç

Engelden kaçan robot

HC-SR04 mesafe sensörü öndeki engeli algılar. Mesafe 20 cm’den azsa robot durur, geriye çıkar, sağa döner ve tekrar ölçüm yapar.

Arduino UNO + L298N

Gerekli malzemeler

  • Arduino UNO ve USB kablosu
  • 2WD robot şasisi, 2 DC motor ve tekerlek
  • L298N motor sürücü modülü
  • HC-SR04 ultrasonik mesafe sensörü
  • 4×AA pil yuvası (motorlar için), jumper kablolar
  • İsteğe bağlı: sensör için servo motor

Bağlantılar

ParçaArduino / güç
HC-SR04 TRIGD9
HC-SR04 ECHOD10
L298N IN1, IN2D2, D3
L298N IN3, IN4D4, D5
L298N ENA, ENBD6, D11 (PWM)
GNDArduino, sürücü ve pil eksi ortak

Arduino kodu

#define TRIG 9
#define ECHO 10
#define IN1 2
#define IN2 3
#define IN3 4
#define IN4 5
#define ENA 6
#define ENB 11

long mesafeCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(3);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long sure = pulseIn(ECHO, HIGH, 25000);
  if (sure == 0) return 400; // yankı yok: uzak kabul et
  return sure * 0.0343 / 2;
}

void dur() {
  analogWrite(ENA, 0); analogWrite(ENB, 0);
  digitalWrite(IN1, LOW); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW); digitalWrite(IN4, LOW);
}
void ileri() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
  analogWrite(ENA, 155); analogWrite(ENB, 155);
}
void geri() {
  digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH);
  analogWrite(ENA, 145); analogWrite(ENB, 145);
}
void sagaDon() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH);
  analogWrite(ENA, 150); analogWrite(ENB, 150);
}

void setup() {
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);
  pinMode(ENA, OUTPUT); pinMode(ENB, OUTPUT);
}
void loop() {
  long cm = mesafeCm();
  if (cm > 20) {
    ileri();
  } else {
    dur(); delay(180);
    geri(); delay(350);
    dur(); delay(120);
    sagaDon(); delay(420);
    dur(); delay(100);
  }
  delay(40);
}

Hareket yönü tersse ilgili motorun iki kablosunu yer değiştir. Dönüş süresini şasi ve zemine göre ayarla.

Proje 02 · orta seviye

Çizgi izleyen robot

İki IR sensörle siyah çizgiyi beyaz zeminden ayırt et. Aşağıdaki örnek sensör çıkışı siyah çizgide LOW varsayar; sensör modülüne göre HIGH/LOW değerini tersine çevirmen gerekebilir.

2 IR sensör + L298N

Bağlantı özeti

IR sol / sağ OUTA0 / A1
L298N IN1–IN4D2, D3, D4, D5
L298N ENA / ENBD6 / D11 (PWM)
GüçMotor pili → L298N; ortak GND

Önce sensörleri yere yakın sabitle. Siyah ve beyaz yüzey üzerinde çıkışları kontrol ederek eşik/lojik ayarını yap.

Temel izleme mantığı

int sol = digitalRead(A0);
int sag = digitalRead(A1);
// Varsayım: siyah çizgi = LOW
if (sol == LOW && sag == LOW) {
  ileri();                 // çizgi iki sensörün altında
} else if (sol == LOW) {
  solaDuzelt();            // çizgi sola kaymış
} else if (sag == LOW) {
  sagaDuzelt();            // çizgi sağa kaymış
} else {
  dur();                   // çizgi kayboldu
}

Bu mantık, Proje 01’deki motor fonksiyonlarına uygun solaDuzelt() ve sagaDuzelt() fonksiyonları eklenerek tamamlanır.

Proje 03 · orta seviye

Bluetooth kontrollü robot

HC-05 Bluetooth modülü üzerinden seri karakter komutları al. Telefonundaki Bluetooth terminal uygulamasından F, B, L, R ve S gönder.

Arduino UNO + HC-05

Bağlantı özeti

HC-05 TXD → ArduinoD10
Arduino D11 → HC-05 RXDGerilim bölücü üzerinden
L298N IN1–IN4D2, D3, D4, D5
L298N ENA / ENBD6 / D9 (PWM)
GNDArduino, HC-05, sürücü ortak

HC-05 RXD lojik girişi 3.3 V olabilir; Arduino D11’in 5 V çıkışını direnç bölücü ile düşür. Modülü doğrudan 5 V lojik sinyale bağlama.

Komut alımı

#include <SoftwareSerial.h>
SoftwareSerial bluetooth(10, 11); // RX, TX

void setup() {
  bluetooth.begin(9600);
  // pinMode ile motor pinlerini OUTPUT yap
}
void loop() {
  if (!bluetooth.available()) return;
  char komut = bluetooth.read();
  switch (komut) {
    case 'F': ileri(); break;
    case 'B': geri(); break;
    case 'L': solaDon(); break;
    case 'R': sagaDon(); break;
    case 'S': dur(); break;
  }
}

Yukarıdaki hareket fonksiyonlarını Proje 01’deki sürücü pinlerine göre ekle. HC-05 için yaygın varsayılan seri hızı 9600 baud’dur.

Kurulum adımları

Şasiyi kur

Motorları, tekerlekleri ve pil yuvasını sabitle. Kabloların tekerleğe sürtmediğini kontrol et.

Kabloları bağla

Motorları Arduino pinlerinden besleme. Motor gücünü motor sürücüye ver, GND hatlarını ortakla.

Kodu yükle ve dene

Arduino IDE’de UNO ve doğru portu seç. Robotu önce tekerlekleri havadayken kısa süre test et.

Güvenli montaj: DC motorları doğrudan Arduino pinlerine bağlama; L298N gibi motor sürücüsü kullan. Motorlar için ayrı pil beslemesi kullan ve Arduino ile sürücü GND’sini ortakla. Kabloları değiştirirken USB ve pil gücünü çıkar. L298N’in besleme bağlantısı/modül jumperları kart sürümüne göre değişebilir; kendi modülünün işaretlerini kontrol et.
